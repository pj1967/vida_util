1. La recta: y = m·x + bpág. 9

La regresión lineal simple busca la recta que mejor resume la nube de puntos: y = m·x + b, donde m es la pendiente y b el intercepto.

Explicación sencillaPiensa en un taxi. Pagas una cantidad fija al subir (la «bajada de bandera») y luego un precio por cada kilómetro: coste = precio_por_km · km + bajada_de_bandera.
  • m (pendiente) = cuánto sube Y cuando X sube 1 unidad. En el taxi, el precio por km.
  • b (intercepto) = el valor de Y cuando X vale 0. En el taxi, la bajada de bandera.

En los salarios del libro, m será «cuántos dólares más por cada año de experiencia». En nuestro proyecto, m será «cuántos litros cada 100 km más consume un coche por cada kilo de peso».

2. Cómo se encuentra la mejor rectapág. 10

Hay infinitas rectas posibles. ¿Cuál es «la mejor»? Cada recta se equivoca en cada punto: esa distancia vertical entre el dato real y la recta es el residuo (error).

Para medir el error total se elevan los residuos al cuadrado (así no se cancelan positivos con negativos y se castigan más los errores grandes) y se suman: SSE (suma de errores al cuadrado). La mejor recta es la que tiene el SSE más pequeño: es el método de mínimos cuadrados.

2.1 Calcularla a mano con 5 datospágs. 10–11

Datos: 5 estudiantes con horas de estudio x = 1, 2, 3, 4, 5 y nota y = 2, 4, 5, 4, 5. Las fórmulas son:

  • m = Sxy / Sxx, donde Sxy = Σ(x − x̄)(y − ȳ) y Sxx = Σ(x − x̄)². Aquí x̄ = media(x) = (1+2+3+4+5)/5 = 3.
  • b = ȳ − m·x̄ (la recta siempre pasa por el punto central (x̄, ȳ)). Aquí ȳ = media(y) = (2+4+5+4+5)/5 = 4.

Medias: x̄ = 3, ȳ = 4. Entonces m = 6/10 = 0,6 y b = 4 − 0,6·3 = 2,2: la recta es nota = 0,6·horas + 2,2. Cada hora de estudio sube la nota esperada 0,6 puntos.

Código Python (copiar y ejecutar)
import numpy as np
# 5 estudiantes: horas de estudio (x) y nota del examen (y)
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])
x_med, y_med = x.mean(), y.mean()          # los "centros" de la nube
Sxy = np.sum((x - x_med) * (y - y_med))    # cuánto se mueven JUNTAS x e y
Sxx = np.sum((x - x_med) ** 2)             # cuánto se mueve x por sí sola
m = Sxy / Sxx                              # pendiente
b = y_med - m * x_med                      # intercepto: la recta pasa por (x̄, ȳ)
print(f"x̄ = {x_med}, ȳ = {y_med}, Sxy = {Sxy}, Sxx = {Sxx}")
print(f"Pendiente m = {Sxy}/{Sxx} = {m} | Intercepto b = {y_med} - {m}·{x_med} = {b}")
y_pred = m * x + b                         # lo que predice la recta
resid = y - y_pred                         # lo que se le escapa
SSE = np.sum(resid ** 2)                   # error de la recta
SST = np.sum((y - y_med) ** 2)             # error si solo usáramos la media
print("\nPredicciones:", y_pred.round(2), "| Residuos:", resid.round(2))
print(f"SSE = {SSE:.2f} | SST = {SST:.2f} | R² = 1 - SSE/SST = {1 - SSE/SST:.2f}")
print(f"Predicción para 6 horas: {m*6 + b:.1f} puntos")

Explicación sencillaLos residuos suman ≈ 0 siempre que la recta tenga intercepto: lo que sobra por un lado compensa lo que falta por el otro. SSE = 2,40 es el error total de nuestra recta. ¿Es mucho o poco? Para saberlo necesitamos un punto de comparación: R².

3. R²: ¿cuánto explica la recta?págs. 12

R² compara dos errores: el de la recta (SSE) y el que tendrías si no usaras X y predijeras siempre la media de Y (SST, suma total de cuadrados). La fórmula es R² = 1 − SSE / SST.

Con los datos del ejemplo: SST = 6 (error si solo usamos la media) y SSE = 2,4 (error con la recta). Así R² = 1 − 2,4/6 = 0,60.

Explicación sencillaR² = 0,60 significa: la recta elimina el 60 % del error que tendrías sin ella; o, dicho de forma habitual, «explica el 60 % de la variación de Y». R² = 1 es un ajuste perfecto; R² = 0, una recta que no mejora a la media.

Atención«Bueno» o «malo» depende del problema: en datos de personas, un R² de 0,3 puede ser útil; en física, uno de 0,9 puede ser insuficiente.
NotaRelación con r: en regresión simple R² = r². Con r = 0,7746, r² = 0,60.
