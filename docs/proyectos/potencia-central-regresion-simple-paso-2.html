📖 Explicaciónqué hacemos y por qué

🎯 Qué hacemosDescargar la tabla de la central y quedarnos con dos columnas: temperatura y potencia.
🔧 Cómofetch_ucirepo(id=294) pide el conjunto nº 294 al repositorio UCI. Con pandas montamos una tabla (df) con las dos columnas.
💡 Por quéLa regresión simple usa una sola entrada (x) y una salida (y). Aquí x = temperatura ambiente e y = potencia eléctrica.
✅ Para quéTener los datos listos en df: con esa tabla trabajaremos en todos los pasos siguientes.
Explicación sencillaUna tabla de datos (en pandas, un «DataFrame») es como una hoja de Excel: cada fila es un registro (aquí, una hora de funcionamiento de la central) y cada columna una variable (temperatura, potencia…).

Código Python
ccpp = fetch_ucirepo(id=294)              # descargar el conjunto de datos nº 294

entradas = ccpp.data.features              # columnas de entrada (AT, V, AP, RH)
salida = ccpp.data.targets                 # columna de salida (PE)

# Nos quedamos solo con la temperatura (x) y la potencia (y), con nombres claros
df = pd.DataFrame({
    "Temperatura": entradas["AT"],         # °C
    "Potencia": salida["PE"],              # MW
})

df = df.dropna()                           # quitar filas incompletas, si las hubiera
