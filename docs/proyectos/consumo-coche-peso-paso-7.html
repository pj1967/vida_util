📖 Explicaciónqué hacemos y por qué

🎯 Qué hacemosUsar la recta para predecir los 80 coches de prueba y medir el error.
🔧 Cómomodelo.predict(X_test) da las predicciones; r2_score, mean_squared_error y mean_absolute_error calculan R², RMSE y MAE.
💡 Por quéR² dice cuánto de la variación explica la recta; MAE es el error medio en L/100 km; RMSE es parecido pero castiga más los errores grandes.
✅ Para quéSaber si el modelo es fiable y cuánto se equivoca.
Cuidado con R²R² = 0,81 no significa «acierta el 81 % de las veces». Significa que la recta explica el 81 % de la variación del consumo; el otro 19 % depende de otras cosas (motor, aerodinámica…).

Código Python
y_pred = modelo.predict(X_test)            # lo que predice la recta para los coches de prueba

comparacion = pd.DataFrame({
    "Peso (kg)": X_test["Peso"].values.round(0),
    "Consumo real": y_test.values.round(2),
    "Consumo predicho": y_pred.round(2),
})
print(comparacion.head(8))
print()

r2 = r2_score(y_test, y_pred)
rmse = np.sqrt(mean_squared_error(y_test, y_pred))
mae = mean_absolute_error(y_test, y_pred)

print("RESULTADOS DEL MODELO (coches de prueba)")
print(f"R²:    {r2:.4f}")
print(f"RMSE:  {rmse:.3f} L/100 km")
print(f"MAE:   {mae:.3f} L/100 km")
