Paso 5 de 10 · Separar entrenamiento y prueba

Cuaderno de Colab · Potencia de una central eléctrica (UCI nº 294)

Sigue las seis secciones en orden: entiende, mira el código, ejecútalo en Colab, compara el resultado e interprétalo con el test.

📖 Explicaciónqué hacemos y por qué

🎯 Qué hacemosDividir los datos en dos grupos: 80 % para entrenar y 20 % para examinar.
🔧 Cómotrain_test_split(X, y, test_size=0.20, random_state=42).
💡 Por quéSi evaluamos el modelo con los mismos datos con los que aprendió, es como ponerle un examen con las preguntas ya vistas. Los datos de prueba son «preguntas nuevas».
✅ Para quéMedir con honestidad cuánto se equivoca. random_state=42 hace que el reparto sea siempre el mismo.

💻 Códigocada línea comentada

Código Python
X = df[["Temperatura"]]                    # entrada (tabla de una columna)
y = df["Potencia"]                         # salida

X_train, X_test, y_train, y_test = train_test_split(
    X, y,
    test_size=0.20,                        # 20 % para prueba
    random_state=42,                       # repartir siempre igual
)

print("Datos de entrenamiento:", len(X_train))
print("Datos de prueba:", len(X_test))
