📖 Explicaciónqué hacemos y por qué

🎯 Qué hacemosDescargar la tabla de coches y quedarnos con dos columnas: peso y consumo, en unidades europeas.
🔧 Cómofetch_ucirepo(id=9) pide el conjunto nº 9 al repositorio UCI. El peso viene en libras y el consumo en millas por galón: lo convertimos a kilos y a litros cada 100 km.
💡 Por quéLa regresión simple usa una sola entrada (x) y una salida (y). Aquí x = peso del coche e y = consumo.
✅ Para quéTener los datos listos en df: con esa tabla trabajaremos en todos los pasos siguientes.
Explicación sencillaUna tabla de datos (en pandas, un «DataFrame») es como una hoja de Excel: cada fila es un registro (aquí, un modelo de coche) y cada columna una variable (peso, consumo…).
Columna originalSignificado¿La usamos?
weightPeso del coche (libras)Sí: entrada x (la pasamos a kg)
mpgMillas por galónSí: salida y (la pasamos a L/100 km)
horsepower, displacement, cylinders…Potencia, cilindrada, cilindros…No (regresión múltiple)
model_year, originAño del modelo y procedenciaNo
Atención con las unidadesMillas por galón mide «cuánto avanzas con un galón»: cuanto más, mejor. Litros cada 100 km mide «cuánto gastas»: cuanto más, peor. Conviene usar la segunda, porque la relación con el peso es casi una recta (lo verás en el paso 4).
ConversiónFórmulaEjemplo
Libras → kgkg = libras × 0,45363.504 lb → 1.589 kg
mpg → L/100 kmL/100 km = 235,215 / mpg18 mpg → 13,07 L/100 km

💻 Códigocada línea comentada

Código Python
auto = fetch_ucirepo(id=9)                 # descargar el conjunto de datos nº 9 (Auto MPG)

entradas = auto.data.features              # columnas de entrada (peso, cilindrada, potencia...)
salida = auto.data.targets                 # columna de salida (mpg: millas por galón)

# Convertimos a unidades europeas
peso_kg = entradas["weight"] * 0.45359237      # libras -> kilos
consumo = 235.215 / salida["mpg"]              # millas por galón -> litros cada 100 km

df = pd.DataFrame({
    "Peso": peso_kg,                           # kg
    "Consumo": consumo,                        # L/100 km
})

df = df.dropna()                               # quitar filas incompletas, si las hubiera

print("Filas y columnas:", df.shape)
